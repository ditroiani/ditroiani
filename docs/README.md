# Asteroids — mini arcade

Jogo em HTML5 Canvas, JavaScript e CSS, sem dependências. É publicado via GitHub Pages a partir da pasta `docs/` do repositório de perfil.

**Controles:** ←/→ ou A/D para girar, ↑/W para acelerar, Espaço para atirar, P para pausar. Há botões táteis em telas sensíveis ao toque.

**Objetivo:** destrua asteroides e sobreviva. Eles se dividem em fragmentos menores. A pontuação máxima é armazenada localmente no navegador.

O código do minijogo é original para este kit e não representa o histórico de contribuições do GitHub.
